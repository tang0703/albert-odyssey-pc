# 三曜試煉 · 戰鬥 Demo

這是採用新規則的三人對三敵回合制原型。角色與舞台為程式繪製的原創簡易素材，
不是 Albert Odyssey 原作戰鬥還原；不含原作光碟、BIOS、抽取圖片、文字或存檔。

## 開始

Windows x64：完整解壓 ZIP，將 `Triad-Trial.exe` 與 `Triad-Trial.pck` 放在同一資料夾，
雙擊 `Triad-Trial.exe`，按「開始戰鬥」。不需安裝 Godot。

## 操作

- 滑鼠點指令，再選目標，最後按「確認行動」。
- 方向鍵移動焦點，Enter 選擇／確認，Esc 取消選擇或開啟／關閉暫停。
- 全體技能的預覽會列出全部存活敵人與預計傷害。
- 防禦減傷 50%，持續至該角色下次行動開始。
- 藥水全隊每場 3 瓶；治療／藥水不能復活或對滿血隊員使用。
- 「演出 1×／2×」只改演出速度，不影響傷害或行動順序。
- 設定提供音效音量及 1080p／1440p／4K 視窗尺寸；Esc 可返回。
- 勝敗戰報可再戰或回標題；再戰重置 HP、MP、藥水與統計。

設定保存在使用者的 Godot app_userdata「三曜試煉 — Battle Demo」目錄，
檔名 `battle_demo_settings.cfg`。沒有戰鬥中存讀檔功能，不讀取原作或資源驗證台的存檔。

## 規則

每輪按速度排序，每人行動一次；同速按固定出場順序。選指令時停等。
普通攻擊為攻擊減防禦；重擊為 floor(攻擊×1.8) 減防禦；魔法為魔力減 floor(防禦×0.5)。
最少傷害為 1，防禦將傷害減半向下取整。治療恢復魔力×2，藥水恢復 50，均不超過 HP 上限。
敵人攻擊目前 HP 比例最低的隊員；敵方法師 MP 足夠就放火球，否則普通攻擊。

首版沒有命中／暴擊隨機數、異常狀態、逃跑、復活、裝備、養成、地圖連接或手把支援。
音效為程式合成短音；沒有背景音樂。使用系統繁中字型，未附帶商業字型檔。

## 開發者

在上一層專案使用 `tools/battle.ps1 -Action test`、`-Action export`、`-Action run`。
這條建置流程不執行原作資源匯入。角色數值、技能、遭遇與外觀分開設定。
外觀 states 可填入此專案內的影格路徑，空陣列使用程式繪製角色；錨點、比例只影響顯示。
