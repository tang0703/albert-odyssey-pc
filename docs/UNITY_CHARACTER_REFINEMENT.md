# Unity 玩家精修 C1／C2

基準：`cda6631`；使用者指定「更貼近原概念圖」。新素材獨立放在 `art/unity/player-refined-v1`，不覆寫 U4 美術、房間、Cirrus、來源包或遊戲核心。

## C1 靜態模型

重建連續臉部曲面、眼睛及眼瞼定位、較寬的交疊髮束與羽飾；調整眉形、瀏海、圍巾、衣襬及膚色。手臂／手掌重建為連續表面，靴面與靴筒重新融合。保留棕髮、頭帶、羽飾、紅圍巾、綠衣與皮靴的辨識特徵。

Blender 源檔包含可編輯網格、UV 與程序材質；另提供套用烘焙貼圖的源檔。角色專用 2048×2048 色彩、切線空間法線及遮蔽／材質參數貼圖，色彩沒有烘焙場景燈光。Unity URP Lit 使用金屬度、平滑度、法線及 AO。此階段不是最終蒙皮，也沒有新動畫。

靜態檢查通過：80,233 頂點、159,110 三角面；高度 1.125、腳底 Z=0、座標有限、UV 範圍有效、皮膚平滑法線、貼圖尺寸正確。金屬扣件與皮帶嵌片保留必要硬面。這些數字不是效能驗收。

## C2 Unity 審閱

以獨立 Unity 審閱程式輸出舊版與新版各四方向、中性光／暖光臉部近景及房間比例。舊版先取樣待機首姿勢，新版為未蒙皮靜態姿勢；不以此宣稱動畫已完成。審閱入口不建立遊戲核心、不執行來源事件。

近景兩版本共用相同主光、0.28 強度補光與陰影設定。近景陰影範圍為 6，normal bias 0.15、depth bias 2；房間比例畫面恢復原有暖光、無額外補光、45° 鏡頭、陰影範圍 25 與原 bias 1。這些近景設定只屬審閱工具，未改遊戲房間。

審閱頁：`art/unity/player-refined-v1/review.html`。核准狀態與素材雜湊：同目錄 `review-lock.json`。

## 驗證與保留證據

- 重新開啟 Blender 源檔檢查模型／UV，核對色彩與材質輸入雜湊；報告位於本地 `reports/unity/character-c1-validation.json`。
- 舊 U4 16 個輸入雜湊、十一份舊包 254 檔案核對未變。未改核心，因此 C4 的 7,370 次對照與整套遊戲回歸留待新蒙皮整合後執行，不能把舊結果當成本輪已重跑。
- 初次 UV 清理遇到空 active layer；改用實際圖層數檢查。Unity 首次建置誤匹配隱藏 preview clip，已明確排除。
- 初次髮束面向反轉已修正；統一烘焙與匯出的三角面。臉部分段陰影經停用陰影／法線的隔離比較，確認主要來自全房間陰影參數用於近景，已將近景設定分開。
- 曾因沙箱無法寫入 Blender 使用者縮圖快取而出現縮圖錯誤；模型儲存、重開與雜湊核對仍通過，不改使用者全域設定。
- 全面要求所有面平滑的初版檢查不適用於金屬扣件與皮帶硬面，已改為檢查皮膚並記錄硬面材料；未將該失敗當成模型通過。
- 所有建置、截圖與失敗日誌保留本地 `reports/unity/character-*`，不以成功重試覆蓋。
