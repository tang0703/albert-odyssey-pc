# MAP001 角色行走驗證台

完整解壓 Windows ZIP 後執行 `MAP001-Character.exe`，不需要 Godot 編輯器。保留同目錄 `.pck`、`scene`、`character`、`character-hd`；任何必要檔案缺少或雜湊不符都會拒絕啟動。

本版在已驗證的 MAP001 室內域提供四方向角色待機與行走，可切換高清、原作像素與診斷標記。高清造型使用核准的四方向設計，每方向一待機與 12 張行走；過渡影格共用原作計時，不改移動、碰撞或來源動畫狀態。

| 操作 | 按鍵或介面 |
| --- | --- |
| 四方向行走 | 方向鍵／WASD |
| 暫停／恢復 | Space |
| 單步 | `.` |
| 重設 | R |
| 格網及軌跡 | F1 |
| 原作對照 | 模式及路線選單；1～4 選路線 |
| 外觀切換 | F2／外觀選單；預設高清 |

多方向同按不移動；放開按鍵後仍按已驗證的原作規則處理待修正位移。查詢未驗證格時顯示「測試邊界」，不補猜測牆壁。自由行走與來源對照分開，後續原作座標只供比較，不回填核心。

背景維持原作比例與最近鄰放大；高清角色提供新製作的外觀，不能把其像素當作原作影格。家具及前景僅涵蓋已核對範圍，影子及裝飾物 6／7 未還原。本版不含 NPC、對話、戰鬥連接或存讀檔；不是完整地圖或完整遊戲重製。

含原作素材的套件僅限本地。交付、SHA256 與實際驗收範圍請讀同目錄 `CHARACTER_DELIVERY.md`、`BUILD-INFO.json`；工具通過不代表 4K 效能或全場景還原通過。
