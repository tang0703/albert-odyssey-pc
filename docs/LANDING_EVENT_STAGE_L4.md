# 落點事件整合與功能驗證

獨立入口 `exploration-demo/landing_event_main.tscn`、核心 `landing_event_core.gd` 與第九包 `landing-event`。原八包及各舊核心的核准雜湊、停止條件維持不變。

新事件核心推演六段、46 條具名指令，包含角色槽分配、四方向角色 50 動畫、固定／追蹤鏡頭、兩段文字等待與事件後背景動作。主劇情為 `07 → 0f`，武器與物品不因事件改變。PC 面板在事件完成後沿用另外核對過的卸下／重裝語意；不宣稱重現原作選單導航。

顯示層預載九張來源角色姿勢，依模型的圖像索引、鏡射與座標選擇，不把來源後續狀態回填核心。原作背景及前景沿用舊落點圖集。新顯示時序從本次完整事件重新量測，角色與鏡頭共同排入兩更新佇列；淡入淡出另依當前來源色偏更新。

新的對話控制器接受核准的一、二、三、五頁段落，確認帶有世代與頁碼，拒絕過期或重複回應。既有互動入口僅將對話欄位標為 `RefCounted` 介面，以便新入口替換控制器；舊入口仍建立原來的一／二頁控制器，沒有放寬其頁數限制。原契約在核心配置後才複製為顯示層文字聯集。

測試入口：

- `test_landing_event_core.gd`：從原房起點連續推演四條完整序列，檢查裝備、事件槽、角色、鏡頭、場景物件與背景循環。
- `test_landing_event_dialogue.gd`：新按下、長按、重複及過期確認、重設與非法頁數。
- `test_landing_event_ui.gd`：三外觀來源重播、自然操作流程、事件各階段暫停／單步／失焦／重設、裝備、再進入及合成 30／60／120 FPS 分割。
- `test_landing_event_input.gd`：實際 Viewport 滑鼠命中與鍵盤事件派送。
- `test_landing_event_gpu.gd`：少量固定畫面的像素正確性，不量測 FPS 或長測。
- Python bundle／package 測試：缺檔、變更、未知腳本、來源資料混入、錯誤入口與偽稱效能通過。

個別實測結果以 `reports/landing-event/l4-*.json` 及候選交付報告為準；此文件列出設計與測試範圍，本身不取代通過證據。

實測結果：四條路線以高清、原作、標記各完整推演，共 42,891 次 UI 來源對照；118 項操作／時序檢查與 20 項實際 Viewport 鍵鼠派送檢查通過。獨立整頁對話控制器 22 項檢查通過。Compatibility 實際渲染的 13 個固定案例均為零像素差異，保留來源對話及影子排除範圍，沒有測量 GPU FPS。
