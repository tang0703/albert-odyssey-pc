# MAP001 同室內探索與鏡頭驗證

完整解壓縮後執行 `MAP001-Room.exe`。不需 Godot 編輯器、光碟映像、BIOS 或原作存檔。
必須保留同層的四個資料夾 `scene`、`character`、`character-hd`、`room`，不得混用其他版本。

| 操作 | 按鍵 |
|---|---|
| 四方向行走 | 方向鍵／WASD |
| 暫停／恢復 | Space |
| 暫停並推進一次完整更新 | `.` |
| 重設玩家、鏡頭、動畫和顯示佇列 | R |
| 切換診斷疊圖 | F1 |
| 高清／原作像素／位置標記 | F2 或下拉選單 |
| 原作路線重播 | 選取「原作對照」及路線，按播放 |

只接受一個方向；同時按多方向會凍結整體更新。失焦會清除已按方向鍵。
選單提供五條室內來源路線。原作狀態僅供比較，重播由輸入序列推動。
橘線為階梯事件／出口的「測試邊界」，不切換場景；持續按住不會觸發事件或穿越邊界。

固定原作 320×224 比例，以來源鏡頭捲動，沒有自由鏡頭或平滑跟隨。
背景保持原作像素，52 幀高清玩家外觀沿用核准版本。F1 關閉診斷疊圖可查看純場景。
支援 1080p、1440p、4K；本輪交付效能目標為 60 FPS。

範圍為同一室內的已驗證可達動線、613 個實際查表格、家具與裝飾物 6／7。
原作影子尚未重現；沒有 NPC、對話、相鄰場景、戰鬥或存讀檔。
完整 MAP001 與 Stage B 尚未因此通過。含原作素材的套件僅留本地。
