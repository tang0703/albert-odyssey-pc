# MAP001 Unity 起始房間候選版

完整解壓 ZIP，開啟 `MAP001-Unity-StartRoom.exe`。請保留旁邊的 Data、MonoBleedingEdge、D3D12 等資料夾與 DLL，不需安裝 Unity 編輯器。

## 如何取得及裝備武器

1. 從兩張床之間往下走，接近桌子右側的 Cirrus 位置，朝向物件按 Enter／「互動」。
2. 對話出現後，每頁放開再按 Enter／「繼續」。等待取得動作完成。
3. 按 E／「裝備」，選「裝備 Cirrus」，再按 Enter 或直接點按該按鈕。
4. Esc／「返回探索」關閉面板；往右側樓梯前進。已裝備分支會停在「測試邊界」，本版不下樓。

若沒有發生互動，靠近並調整朝向後再按；不需反覆長按。F1 可顯示來源位置診斷。未持有或已裝備時，無效操作不會複製物品。要卸下時，在裝備面板選「卸下 Cirrus」。

| 操作 | 按鍵 |
|---|---|
| 移動 | 方向鍵／WASD；同時多方向不移動 |
| 互動、翻頁、選單確認 | Enter；按住不連續確認 |
| 裝備面板 | E；面板開啟時暫停房內更新 |
| 面板選項／返回 | 上下方向鍵／Esc |
| 暫停／繼續 | Space |
| 暫停時單步 | `.` |
| 從任意階段回完整起點 | R |
| 診斷／3D與標記切換 | F1／F2 |

失焦自動暫停，返回後按 Space。重設會清除取得、裝備、劇情、音訊及待處理輸入。鏡頭固定，沒有旋轉或縮放。

需要指定視窗大小時，可建立捷徑，在目標末尾加入 `-screen-width 2560 -screen-height 1440 -screen-fullscreen 0`；1080p 使用 1920／1080，4K 使用 3840／2160。

## 內容與限制

本版使用核准第二版人物方向、22 骨骨架、待機／行走及四個取得姿勢、URP 材質與即時陰影。`Editable-3D` 內有 Blender、FBX、UV 與貼圖；`Animation-Previews` 有四方向與動作預覽。

玩法、碰撞及事件由來源整數核心計算，3D 模型和動畫不推動位移。造型、照明與固定俯視鏡頭是新的視覺呈現，並非原作畫面逐像素還原。

只包含起始房間至樓梯轉場提交前。樓下、LAIA、戰鬥與存讀檔未移植；Godot 舊版保留。本地套件包含來源資料及音訊，留本地使用。

**效能未驗收。沒有負載、長循環、效能基準或實際 GPU FPS 測試。**
