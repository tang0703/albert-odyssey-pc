# 三曜試煉 · 戰鬥 Demo 驗收

2026-09-10。採使用者核定的新規則，不再以原作戰鬥逆向作為此 demo 的前置條件。
三人對三敵、固定一場遭遇、原創程式繪製人物／舞台與合成音效。
既有資源驗證台維持獨立，原作 Stage B／完整可玩切片未因此通過。

## 交付與結構

- `build/battle-demo/Triad-Trial.exe` 與同目錄 `.pck`：Windows x64 release。
- `build/Triad-Trial-Windows-x64.zip`：執行檔、資料包、操作說明、Godot MIT 與第三方聲明。
- `battle-demo/core.gd`：不依賴節點、演出時間或 FPS 的規則核心。
- 指令帶 actor/action/target/token；完整驗證後才扣 MP／道具並輸出事件。
- 角色數值及技能置於 encounter 定義；外觀置於 appearances 定義，影格、錨點、顯示比例不參與規則。
- 16-bit 合成音效即時生成，不引用音樂檔或原作錄音。沒有背景音樂。
- 設定獨立儲存音量、解析度、演出速度；沒有戰鬥中存讀檔或舊存檔遷移。

原始光碟、BIOS、原作素材、文字、存檔、測試碼、逆向報告均不在包內。

## 畫面與效能

Windows release 已冷啟動並產生 1920×1080、2560×1440、3840×2160 PNG。
畫面驗收包含全體技能預覽、數值、確認／取消按鈕及人物標記。
尺寸以實際讀回的 PNG 為準，避免高 DPI 下 texture 寬高回報與實際渲染影像不同。

4K 長時間循環測試的數據與交付雜湊記錄於 `battle-demo-validation.json`。
使用本機 RTX 4070 Ti SUPER，限制最高 60 FPS；前兩秒不列入影格統計。
遊戲程序記憶體由 Windows 取樣；顯存數值為 Godot renderer 追蹤值，不等於整張 GPU 的佔用。
Release 版 MEMORY_STATIC 回報 0 時視為不可用，不解讀為零記憶體消耗。

## 限制

本版美術為簡易替代角色，演出為短動作、閃爍、數字飄字與倒下；不是原作人物或高清重繪。
沒有裝備、成長、地圖、逃跑、異常狀態、手把、多人或背景音樂。
系統字型為本機繁中字型 fallback，未散布商業字型。
本機測試不代表所有硬體都達到 60 FPS。

Godot 在沙箱測試環境會記錄既有 Windows 根憑證讀取錯誤；本 demo 不使用網路，
未修改系統憑證、全域 PATH 或登錄檔。測試期間 APPDATA 僅作程序層級指向專案 reports。
