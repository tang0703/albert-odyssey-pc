## 實作

獨立 `character_main.tscn` 入口預設高清模式，F2 或下拉選單切換高清／
原作／診斷標記。52 個 AtlasTexture 和四張圖集在開始前預載，演出中
沒有 PNG 解碼或檔案讀取。原作像素、背景與家具採最近鄰，高清角色線性取樣。

高清選圖保留原作每輪 40 更新與三更新的已驗證顯示延遲。分數 render phase
只用於每個主要姿勢內的三張圖，不能寫入移動狀態。暫停保留分數時間，
單步推進一次來源更新並歸零分數，重設清除完整佇列；多鍵同按凍結更新及相位。

每次提交演出前驗證即將顯示／排程的必要原作幀與三張高清子幀；純渲染
跨子幀前也先驗證。缺圖時拒絕並保留上一次座標、佇列與時鐘，沒有替代人物。

HD 建置拒絕把舊審閱素材重新綁到不同來源。全新暫存包驗證後才發布，
既有包僅允許完全相同的冪等建置，異版不覆寫。目錄與外置 pin 是分別發布：
若在兩者之間中斷，新包會因缺少 pin 而拒絕載入；不聲稱跨檔交易原子性。
