# MAP001 樓梯前 Cirrus 事件

完整解壓縮後執行 `MAP001-Event.exe`。無需安裝 Godot；請保留五個相鄰資料夾。本套件含本地來源素材，不供公開分享。

往右側樓梯前移動，會觸發玩家表情、鏡頭移動、Cirrus 動畫與兩頁對話。確認後等待玩家退回，鏡頭回復才可繼續行走。再次進入可以再次觸發。真正出口仍為「測試邊界」。

| 操作 | 按鍵 |
|---|---|
| 四方向移動 | 方向鍵／WASD |
| 對話下一頁 | Enter／滑鼠「繼續」；每次新按下一頁 |
| 暫停／恢復 | Space |
| 暫停時單步 | `.` |
| 完整重設 | R |
| 診斷疊圖 | F1 |
| 高清／原作／標記 | F2 |

多方向同按凍結整次更新。失焦自動暫停並清除按鍵；回來後按 Space 恢復。對話整頁顯示，不加逐字動畫、語音或選項。若很快確認完兩頁，會先完成 Cirrus 的必要演出，再進入後續退回動作。繁中沿用現有譯文，說話者保留來源名稱 CIRRUS。

「原作軌跡對照」包含中央、上側、下側、再次進入、等待、長按六條來源路線。這個模式使用原作裝置回應核對事件規則；自由行走則使用 PC 整頁翻頁與實際本地音訊回應。兩種裝置呈現的耗時不同，不能當成原作逐字排版或光碟載入時間的還原。

高清玩家為核准的 52 幀外觀；表情與 Cirrus 沿用來源像素素材。背景、移動、碰撞和鏡頭保持來源規則。影子仍省略。未加入相鄰場景、戰鬥串接、存讀檔或新美術。完整 MAP001 與 Stage B 尚未完成。

驗證與效能結果見 `EVENT_VALIDATION.json`、`EVENT_DELIVERY.md`。來源流程及兩頁對照見 `EVENT_SOURCE_PROGRESS.md`。九項需要遺失舊快照的回歸仍未能重跑；實際 GPU 120 FPS 未列為本次驗收。
