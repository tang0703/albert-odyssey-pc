# 人物造型工具再評估

查核日期：2026-11-01。v2 使用者回覆「需在精修，評估使用其他建模工具，讓3d圖與概念圖接近」，因此 v2 未核准，維持 C2 造型關卡；原封存模型、審閱頁及雜湊不改。最新決定見 `docs/character-v2-review-decision.json`。

## 結論

建議改為「多視角參考生成初始幾何 → 逐部位雕刻修形 → Unity 同條件審閱」。免費優先時，以 Hunyuan3D-2mv 的本機幾何生成作首個小樣候選，Blender 保留作雕刻、整理網格與匯出；Meshy／Tripo 的多視角服務作付費備選。本輪完成文件評估，尚未安裝、付費、上傳概念圖或生成新模型，不能宣稱任一候選已達到概念圖相似度。

目前不足不能歸因於 Unity 或 Blender 能力：v2 使用程序化曲面與規則髮束，雖可產生有效網格，仍缺少原概念的眉眼神情、自然髮流、衣物受力與材質層次。單換軟體、增加面數或沿用相同幾何生成方式，不足以改善這些問題。Blender 本身已有雕刻及動態拓樸能力。[官方雕刻功能](https://www.blender.org/features/sculpting/)

## 候選工具

| 工具 | 官方可確認的能力 | 本案用途與限制 | 判斷 |
|---|---|---|---|
| Hunyuan3D-2mv | 多視角圖像生成形狀；本機 API、Windows 支援與低顯存模式 | 可用核准的前／側／背造型作幾何約束；需另建依賴環境，輸出仍需修形、拓樸與材質處理 | 免費優先的小樣首選；不預先保證品質 |
| Meshy | 多視角圖生 3D、可匯出常見模型格式 | 減少本機推論環境工作；多視角不在 Free 方案，需帳號及額度 | 付費備選，先試同一角色再決定 |
| Tripo | 2–4 張多視角輸入，提供高細節／網格整理選項 | 可比較頭髮、衣襬與背面一致性；多視角列於 Pro 工具，Free 模型公開且非商用 | 付費備選，不將免費單圖結果冒稱多視角驗證 |
| ZBrush | 專用數位雕刻、角色造型與繪製 | 適合精細雕刻，但仍需要逐部位藝術判斷與實際操作；本機未核對有效授權，不先導入 | 有合適雕刻流程與授權時再考慮；不是自動還原概念圖的捷徑 |
| Blender（保留） | 雕刻、動態拓樸、模型整理 | 改用參考圖約束的雕刻／網格編修，不延續程序髮束堆疊作最終造型 | 留作編修與 Unity 匯出工具 |

## 本機可行性

本輪僅執行硬體資訊查詢 `nvidia-smi --query-gpu=name,memory.total --format=csv,noheader`：RTX 4070 Ti SUPER，16,376 MiB。不是負載或 FPS 測試。

- Hunyuan3D-2 官方 README 列形狀生成約 6 GB、形狀加材質共約 16 GB，並另列 2mv 模型與低顯存啟動方式。這是系列文件需求，不是本機 2mv 已驗證峰值；建議先只做形狀，不將 16 GB 硬體直接判為完整材質流程可用。[官方說明](https://github.com/Tencent-Hunyuan/Hunyuan3D-2)
- Hunyuan3D-2.1 官方列形狀 10 GB、材質 21 GB、合計 29 GB。2.1 全流程不作本機預設；形狀單階段可列備選，但不能因版本較新就認定四方向約束或結果更適合。[官方需求](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1)
- 仍待核對：隔離 Python／PyTorch／CUDA 依賴、模型下載容量與雜湊、授權條款、Windows 擴充編譯需求及單次產出是否成功。這些尚未實作，不宣稱工具可用。

## 下一個小樣的具體範圍

1. 鎖定同一組核准概念圖，分離四方向參考與文字背景；核對頭帶／羽飾側別、髮根、圍巾結、衣襬及比例，不用新的生成插畫取代原目標。多視角之間若有矛盾，先明列並選定對應設計；不能要求模型同時滿足互相矛盾的形狀。[Tripo 官方多視角準備指引](https://www.tripo3d.ai/product-doc/model-generation/multi-view-to-3d)
2. 先做頭臉＋髮型的小樣，生成少量初始幾何；同時保留現有 v2 作比較。不得只用帶陰影的貼圖掩蓋扁平或錯誤幾何。
3. 輸出未貼圖與基本材質兩組 Unity 靜態畫面。以同角度、同大小核對額頭／下巴、眼型、鼻口、髮束走向、髮根空洞、羽飾與側後面。若小樣仍不像，就淘汰該流程，不先製作整身。
4. 頭部方向通過後才處理服裝、分件及最後材質。保留可編輯模型、來源輸入、生成參數、版本與雜湊。

驗收依使用者造型審閱與實際 Unity 畫面，不以面數、工具宣傳或圖片相似度單一分數代替。保持 1.125 身高、腳底錨點、原遊戲狀態及房間不變；不做動畫、負載、長循環、效能基準或實際 GPU FPS 測試。
