# MAP001 兩場景與 LAIA 2.5D 功能候選版

完整解壓後執行 `MAP001-25D-Landing.exe`。EXE、PCK 與十一個資料目錄必須保留相對位置，無需 Godot 編輯器。本套件含本地來源素材，只供本地驗證；不要將整包公開上傳。

## 可玩流程

在原房取得 Cirrus，按 E 裝備，再走向樓梯下樓。樓下沿通道向左接近 LAIA，使用 Enter 或「繼續」依序確認五頁與三頁對話，等待角色返回及控制恢復。事件後可在既有 98 個已驗證查表格的範圍行走，其他出口與事件仍為測試邊界。

- 方向鍵／WASD：移動；同時多方向不移動。
- Enter／互動：起始房間互動或確認一頁對話；按住不連續翻頁。
- E：開關精簡裝備面板；Esc 關閉；事件期間禁止開啟。
- Space：暫停；`.`：暫停時單步；失焦自動暫停並清除按鍵。
- R：從任意階段回到原房完整起點，保留外觀選擇。
- F1：診斷疊圖；F2：2.5D／既有高清／原作像素／標記。
- 右側路線及重播選單用於已驗證來源對照；不會擴大可行走範圍。

## 美術與資料

新入口預設兩層樓皆使用暖光木造固定全景，448×256 世界範圍等比置於 16:9 容器。這是新的構圖，來源鏡頭仍運算供驗證，並非宣稱原作鏡頭如此呈現。其他外觀維持來源鏡頭。

LAIA 52 張透明 PNG、四張圖集、四方向 GIF 位於 `ANIMATION/`。她的來源步態為 48 次更新一輪，玩家仍為 40 次。新增過渡僅影響顯示；原地特殊動畫依 LAIA 自身來源游標取樣，不因沒有位移而切成待機。未在本事件使用的正面造型只列美術預覽。

`ART-LAYERS/landing-layers.ora` 可用 Krita 開啟；包含十三個獨立場景圖層。配套 JSON 保存世界投影及動態物件的定位，角色、蒸氣與玩家動畫獨立預載。完整生成提示詞與原始圖保留在 Git 美術目錄。接地陰影為新增美術效果，原作影子仍未還原。

素材缺失、修改或未列入核准清單會拒絕啟動，請勿混用前版資料目錄。舊起始房間入口及所有前版套件保持原樣。

## 驗證範圍

四外觀完整路線比較 57,188 次更新；新入口鍵盤／滑鼠、取消與重設、對話防連點、切換外觀、暫停及合成 30／60／120 FPS 時間分割均屬功能測試。三解析度短程畫面、來源提交、ZIP 逐檔雜湊與解壓啟動結果見 `VALIDATION.json`、`REPORTS/`、`SCREENSHOTS/` 及本地交付報告。

**效能未驗收。** 本輪未執行負載、長循環、效能基準或實際 GPU FPS 測試。九項缺失舊快照測試與七項效能相依測試仍列未能重跑／略過；短程畫面與封裝通過不代表效能通過。

起始房間既有特殊像素演出未擴修。雙向往返、完整探索、原作影子、前版效能驗收及 Stage B 整體仍未完成。
