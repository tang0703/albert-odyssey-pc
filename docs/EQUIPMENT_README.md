# MAP001 最小裝備流程：Windows 功能候選版

完整解壓後執行 `MAP001-Equipment.exe`。七份相鄰資料包必須保留；不需要 Godot 編輯器、光碟、BIOS 或原作快照。來源素材只供本地驗證。

**效能未驗收。** 本輪沒有執行負載、長時間循環或效能基準測試。1080p／1440p／4K 的短程畫面檢查不代表 60 FPS、記憶體或顯存驗收。

## 操作

| 操作 | 鍵盤／滑鼠 |
|---|---|
| 移動 | 方向鍵／WASD；同時多方向不移動 |
| 與桌上 Cirrus 互動、對話繼續 | Enter／互動或繼續按鈕 |
| 開啟武器面板 | 自由行走時 E／裝備按鈕 |
| 選擇操作 | 面板內方向鍵 |
| 裝備或卸下 | Enter／對應按鈕 |
| 關閉面板 | Esc／E／返回探索 |
| 暫停、單步 | Space；暫停後按 `.` 推進一次完整更新 |
| 完整重設 | R／重設按鈕 |
| 疊圖、外觀 | F1；F2 切換高清／原作／標記 |
| 原作軌跡核對 | 右上選擇「原作軌跡對照」與路線，按播放 |

面板開啟時房內更新凍結；面板內單步不推進房間。對話、事件、暫停、來源重播及轉場邊界不能開啟面板。按住 Enter 不會連續操作；失焦會暫停，回到視窗後按 Space 恢復。

## 遊玩流程

1. 從床邊向下走，繞到桌上 Cirrus 的正上方，朝下按 Enter。
2. 閱讀繁中對話，按 Enter，等待拾取與音訊演出完成。
3. 按 E，選擇「裝備 Cirrus」，確認後返回探索。
4. 往右側樓梯前進。走到出口提交點會顯示「測試邊界」，不載入下一房間；按 R 重設。

未裝備便接近樓梯會保留原有提醒。原作允許卸下，卸下後會恢復持有數量，但保留「曾裝備」劇情旗標，因此樓梯後續仍開放。這是已驗證來源行為。

只提供派克的武器槽與 Cirrus，沒有一般背包、能力值預覽、其他裝備或戰鬥。裝備不會替換行走角色造型。來源更新頻率、固定比例、碰撞及玩家動畫不受外觀或面板尺寸影響。

測試與限制見 `EQUIPMENT_DELIVERY.md`，來源操作、記憶體欄位與樓梯分支見 `EQUIPMENT_SOURCE.md`。`BUILD-INFO.json` 記錄二進位來源提交及套件內容雜湊。
