## 已確認流程

正常行走至桌前，朝向 Cirrus 並新按 A／C，觸發 MAP001.TWN `0x2fb4`。
來源使用玩家碰撞形狀投影互動點，再與包含邊界的矩形比對；沒有推定距離圓或通用遮擋判定。
矩形原始座標為 `(11856,27376)–(12208,27648)`。互動判定在輸入閘之後、事件根腳本之前。

首次互動將 `06036938` 從 `01` 改為 `03`，鎖定控制，隱藏場景裝飾 ID `0030`、`0031`。
玩家保持 X，Y 改為 `0x6a70`；播放動畫 24／25、原作 `IVENT176.AIF` 及臨時特效 actor ID `0031`。
臨時 actor 與同 ID 的場景裝飾是不同物件表。動畫結束後刪除特效，恢復玩家模式與色盤。
一頁對話及必要動作完成後，來源將物件計數 `060367cf` 從 0 改為 1，再恢復控制。
再次互動只執行條件與結束指令，不重複取得物件。

互動後再接近樓梯，會進入 `0x2f83` 的「尚未裝備」兩頁提醒，完成表情、鏡頭及退回動作，
最後在原始座標 `(0x3320,0x6940)` 恢復控制。本輪正常操作沒有設置「已裝備」位元；
不以改 RAM 或直接改旗標測試其分支，也不宣稱已能跨場景。
