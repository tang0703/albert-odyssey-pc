# MAP001 首次下樓・Windows 功能候選版

完整解壓後執行 **MAP001-Transition.exe**，不需要 Godot 編輯器。請保留旁邊的 `.pck` 及八個資料目錄，缺少或修改必要檔案會拒絕啟動。這是本地來源驗證版，**效能尚未驗收**。

從原房起點走到 Cirrus 桌前並朝向它，按 Enter 取得；閱讀對話並等待動作完成。按 E 開啟武器面板，裝備 Cirrus 後走向右側樓梯。完成原作淡出、初始化及淡入後，可在落點右側經驗證的通道行走。

若要觀看完整路線，選擇「原作軌跡對照」及「落點通道與接牆」，再按 Space 開始。其他三條路線分別核對裝備、卸下及重裝後下樓；原作使用「曾裝備」旗標，因此裝備後卸下仍能通過樓梯。

| 操作 | 按鍵／方式 |
|---|---|
| 移動 | 方向鍵／WASD；多方向同按凍結更新 |
| 原房互動／對話繼續 | Enter／畫面按鈕；須重新按下，按住不連續翻頁 |
| 裝備面板 | E／「裝備」；方向鍵選擇、Enter 確認、Esc 返回 |
| 暫停／恢復 | Space；失焦也會自動暫停 |
| 暫停單步 | `.`，推進一個完整邏輯更新 |
| 完整重設 | R，從任一階段回到原房起點，還原物品、裝備、旗標及音訊 |
| 診斷疊圖／外觀 | F1／F2；高清、原作、標記不改規則 |

轉場期間禁止移動、互動及裝備。進入新場景後，仍按住的方向／確認鍵請先放開再按。面板開啟時凍結探索，這是 PC 介面政策，不宣稱原作選單導航時序相同。

「測試邊界」代表後續場景、事件或位置尚未開放。未驗證位置可退回；來源已提出後續事件／轉場時停住，按 R 重設。只做單向下樓，沒有回程、目的地完整探索、自由 NPC 互動、戰鬥或存讀檔。

套件附來源流程、狀態交接、覆蓋圖、三解析度短程畫面及功能驗證報告。`TRANSITION_VALIDATION.json` 的 `functional_passed` 與 `performance_tested` 分開記錄；短程畫面、匯出及解壓啟動都不代表效能通過。
