# MAP001 落點左側事件候選版

完整解壓後啟動 `MAP001-Landing-Event.exe`，無需 Godot 編輯器。請保留同目錄所有九個資料夾；程式會核對核准清單、依賴與內容雜湊。

本版流程為原房取得 Cirrus、裝備、下樓、接近左側區域、完成 LAIA 八頁對話與角色／鏡頭演出，再於已驗證範圍行走。事件完成後仍在場景 7；再次進入觸發區不重播主要對話。這不代表目的地整室、回程樓梯或完整 MAP001 已還原。

| 操作 | 功能 |
|---|---|
| 方向鍵／WASD | 四方向移動；多方向同按凍結更新 |
| Enter／互動 | 原房拾取互動；對話中確認一頁 |
| E／裝備 | 自由探索時開啟 Cirrus 武器面板 |
| 方向鍵、Enter、Esc | 面板選擇、確認、返回 |
| Space | 暫停／恢復全部邏輯與演出 |
| `.` | 暫停時單步一次完整邏輯更新 |
| R | 回到原房完整起點，清除事件、裝備與待處理輸入 |
| F1／F2 | 診斷疊圖／高清、原作、標記外觀 |

原房先走到桌上 Cirrus 前方，朝向它按 Enter；完成來源演出後按 E 裝備，再沿右側通道到樓梯。下樓後先向下，再向左接近事件區。也可從路線選單選取來源重播，逐步檢查三種裝備歷程及確認鍵案例。

事件中移動及裝備操作鎖定。確認只接受新按下；按住不連續翻頁。正常遊玩失焦會暫停並清除按鍵；重新聚焦後按 Space 繼續。跨場景及重設時仍按住的遊戲鍵須先放開。自動截圖的焦點隔離只限明確命令列模式。

背景、LAIA 與必要特殊姿勢使用來源像素；高清玩家沿用既有 52 幀。對話為鎖定繁中語料，整頁顯示，與原作逐字演出不同。兩段中英文字及來源頁序可在本地 `landing-event/dialogue.json` 查閱。

畫面上的「測試邊界」表示範圍未核准，不等同原作牆壁。事件強制移動路徑不授予玩家自由探索權限。回程及其他事件／出口仍保留邊界；未新增戰鬥、存讀檔或自由 NPC 互動。

**效能未驗收。** 本輪沒有負載、長循環、效能基準或實際 GPU FPS 測試。短程解析度、畫面與封裝檢查不得解讀為 60 FPS 或記憶體穩定性驗收。來源影子、完整音樂播放、雙向往返、前版效能與 Stage B 整體仍未完成；缺失舊快照的九項測試未能重跑。

本地套件含來源素材，保留在本機；GitHub 僅同步程式、測試、契約識別與不含來源素材的文件。Godot 授權與第三方聲明見隨附檔案。

開發環境可執行 `tools/landing_event.ps1 run` 開啟獨立入口，`tools/landing_event.ps1 test` 重跑功能測試。需先具備九份鎖定本地資料包；這些命令不會執行效能測試。
