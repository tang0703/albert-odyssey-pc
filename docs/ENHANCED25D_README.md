# MAP001 2.5D 起始房間候選版

將整個 ZIP 解壓到同一資料夾，執行 `MAP001-25D.exe`。保留所有十份資料包；不需要 Godot 編輯器。此為功能候選版，**效能未驗收**。

方向鍵／WASD 移動，Enter／互動按鈕與 Cirrus 互動，對話時 Enter／繼續翻頁。E 開啟精簡裝備面板，選取 Cirrus 裝備後關閉面板，前往右側樓梯下樓，再向左接近 LAIA 事件。

Space 暫停，`.` 單步，R 完整重設，F1 診斷疊圖，F2 切換 2.5D／既有高清／原作／標記。多方向同按不移動；失焦暫停並清除輸入。轉場後須先放開仍按住的按鍵。

2.5D 模式只替換起始房間，使用固定全房間 16:9 容器、448×256 世界座標等比置中，沒有修改原作來源鏡頭狀態。下樓後依配置使用既有高清玩家及來源像素場景；R 回原房並保留所選外觀。

四方向共 52 張玩家影格使用原有 40 更新步態相位。接地陰影是新增美術效果。必要拾取姿勢、表情、光效及 Cirrus 特殊姿勢沿用來源像素，不宣稱已重繪所有演出。其他出口仍是「測試邊界」。

本輪沒有負載、長循環、效能基準或實際 GPU FPS 測試。九項舊快照缺失與七項效能相依測試繼續列為不可重跑／略過。短程畫面及封裝驗證不代表效能通過，Stage B 也未整體完成。

套件含本地來源素材，只作本地驗證；不得將原始來源資料、RAM、快照或本套件納入公開倉庫。新繪美術、程式及可編輯圖層配置另由 Git 管理。
