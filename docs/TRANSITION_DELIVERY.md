# MAP001 首次單向轉場・候選版驗收

本輪遵照使用者指示，不執行負載、長時間循環、效能基準或實際 GPU FPS 測試。三解析度短程畫面及 GPU 像素核對只驗證功能與顯示。

來源：三種裝備歷程各三次重播，目的地是來源資源表指向的 MAP001 子場景 7。初始化、控制交接、裝備／物品／劇情保留、必要物件與角色皆由來源還原；沒有跳過事件或強制恢復控制。

落點通道三次重播相同，每次 860,892 項比較零差異。95 個實際查表格、443 次繪製、442 個顯示畫面與 31,629,202 個來源像素比較通過，僅排除既有影子。Godot 核心 80,419 項、三外觀 UI 10,965 次更新／70 項功能檢查、派送輸入 15 項及 13 個實際 GPU 圖像案例通過。

最終封裝狀態、三解析度畫面、回歸計數及執行檔來源提交，以本地候選套件的 `TRANSITION_VALIDATION.json`、`TRANSITION_SCREENSHOTS.json` 與 `BUILD-INFO.json` 為準。候選 ZIP 僅在功能及封裝關卡完成後建立；不把來源驗證完成當成交付完成。

既有舊快照缺失的九項測試仍未能重跑；未更改舊 `savestate-lock.json`。影子、雙向往返、目的地完整探索、前版效能與尖峰確認、實際 GPU 120 FPS 及 Stage B 整體仍未完成。

候選套件名稱：`MAP001-Transition-Candidate-Windows-x64.zip`。原作素材、RAM、快照與含來源套件留在本地；GitHub 同步程式、測試及核准摘要。
