# MAP001 起始房間 2.5D：背景定位與四方向審閱

基準：`a7bb126f848a37f60dea3806142bb9156e3ce007`。沿用「調整強化版為 2.5D 風格」任務已核准的背景 01、人物比例與精修設計。只處理起始房間；樓下及 LAIA 事件沿用目前版本。尚未產出 `MAP001-25D-Candidate-Windows-x64.zip`。

## 已建立的成果

- 已核准參考圖複製至 `art/enhanced25d/v1/references/`，由 Git LFS 管理；來源像素參照仍留本地。
- 使用內建 imagegen 製作四張透明方向打樣、完整房間定位初稿，以及空房底圖、床、桌、兩張地毯、椅子六個獨立素材。每次生成提示詞與原始輸出保留，沒有將概念圖當成已完成的 52 幀動畫。
- `layout.json` 保存各層來源座標、家具視覺範圍與空房圖的校準網格。這些資料只調整美術投影，沒有新增碰撞遮罩或改動核心。
- `tools/enhanced25d_projection.py` 提供精確來源整數座標到固定全房間視窗的投影；等比置中，保留 1/16 單位位置。
- 獨立 Godot 美術審閱專案生成四方向、房間比例、來源軌跡疊圖三張 1920×1080 畫面；沒有接管既有遊戲入口。

## 實測與關卡狀態

九份既有包的核准 manifest 雜湊保持一致。五條室內來源路線在 1080p／1440p／4K 的 **15,183 次投影往返換算零差異**，三項投影與非法輸入測試通過。這是座標投影測試，不能當作新增的核心來源對照或玩法驗收。

實際 Godot Compatibility 渲染生成三張靜態審閱畫面，未量測 FPS、程序／GPU 記憶體或長循環。來源範圍仍為原來 **613 個室內查表格**，預覽格線不是通用障礙旗標。

V1 已完成定位工具與分層候選，**家具遮擋、全部路線的可見腳底及動態物件尚未正式驗收，因此不標記 V1 全面通過**。四方向候選先供 V2 指定的使用者審閱；必須核准後才開始 V3 的 52 幀製作。

尚待完成：

- 四方向與 36 世界單位人物高度的使用者核准。
- 最終透明邊緣與腳底錨點修整；目前以 alpha ≥128 的可見範圍做審閱定位，原始 PNG 未被修改。
- 凳子、Cirrus 的兩個可消失物件及必要動態裝飾整合；目前比例預覽明列使用來源小圖。
- 最終前景遮擋、特殊姿勢、四模式切換、事件狀態交接與完整遊戲回歸。
- 52 張 512×512 PNG、四張圖集、可執行候選 ZIP 與解壓驗證。

四方向背面的頭帶結、圍巾結與服裝接縫屬美術延伸，不新增原作設定或玩法。新角色仍使用穩定 ID `map001_player`，美術稿「派克」標籤不補足來源角色命名證據。

## 重跑審閱

先執行 `tools/prepare_enhanced25d_review.py` 產生本地資料，再以 Godot 執行 `art/enhanced25d/review-project/review.gd`，參數 `--review=directions`、`--review=room` 或 `--review=alignment`。目前專案只是美術檢視器，沒有行走輸入或原作事件執行器。

也可直接執行 `tools/enhanced25d_review.ps1 -Mode all`；工具會保留每次獨立輸出與錯誤紀錄，並只關閉自己啟動的短程審閱程序。

本地證據位於 `reports/enhanced25d/`，來源／房間合成預覽因含原作小圖不提交 Git。純新繪四方向審閱圖保存在美術目錄。所有既有 Windows 交付保持不變。

**效能驗收維持暫緩。** 九項舊快照缺失與七項效能證據相依測試不更動、不假稱恢復通過。新美術尚未進入遊戲，本階段未重跑整套遊戲回歸。
